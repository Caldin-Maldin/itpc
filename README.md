
Для тех, кто пользуется приложением `https://play.google.com/store/apps/details?id=ru.tmtka.itpc.android` или сайтом `https://itpc/` для оплаты за ЖКХ и передачи показаний счётчиков.



Установка

1. Копируем папку с интеграцией в custom_components. Перезагружаем HA.

2. `Устройста и Службы` - `Добавить интеграцию`. Выбираем `"Личный кабинет ТРИЦ"`.

3. Вводим логин/пароль.

4. Появляются следующие сущности 
<img width="305" height="583" alt="photo_2026-05-07_22-11-18" src="https://github.com/user-attachments/assets/dac8863f-081a-498a-8cf2-340140148ff4" />


Передача показаний осуществляется службой `action: itpc.send_values` (показания должны быть целым числом, без десятичных знаков)
<img width="674" height="727" alt="photo_2026-05-07_22-11-53" src="https://github.com/user-attachments/assets/014c790d-d199-46ed-999a-2ee70bb3b5a0" />

Обновление данных - соответствующей службой. 

Автоматическое обновление только при загрузки ХА или после передачи показаний.
